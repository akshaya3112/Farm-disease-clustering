How to Run the Pipeline & Launch Web App

Zero-Config Execution

The entire project is structured for instantaneous, single-command reproducibility.

Option A: Single Batch / Shell Command

Windows: 

.\run_all.bat

Linux / macOS / Bash: 

bash run_all.sh

Option B: Manual Step-by-Step Execution

Step 1: Install dependencies 

pip install -r requirements.txt

Step 2: Execute data science pipeline (Phase A) 

python run_pipeline.py

Step 3: Launch web dashboard (Phase B) 

python app.py

Open http://127.0.0.1:5000 in your web browser.
